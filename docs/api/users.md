# API `api/users.php`

Описание:

Простой JSON API для управления пользователями. Данные хранятся в `api/data/users.json`.

Поддерживаемые действия (`action` в POST JSON):
- `list` — вернуть список пользователей
- `register` — зарегистрировать пользователя (`username`, `passwordHash`, `role`)
- `login` — проверить логин (`username`, `passwordHash`)
- `updateRole` — изменить роль пользователя (`username`, `newRole`) — возвращает обновлённого пользователя
- `delete` — удалить пользователя (`username`)

Формат ответа: JSON с полем `ok` и дополнительными полями (`users`, `user`, `error` и т.д.).

Особенности реализации:
- Сервер сохраняет пользователей в `api/data/users.json` и использует блокировки файлов при записи.
- Пароль хранится как base64-строка (совместимо с клиентским `btoa`).
