# Модуль `js/profile.js`

Описание:

Логика страницы профиля: отображение данных текущего пользователя, права ролей и административная панель для управления пользователями (только для `admin`).

Основные функции:
- `renderProfile()` — отрисовка информации профиля
- `renderAdminUsersTable(currentUsername)` — таблица пользователей и управление ролями/удалением

Интеграции:
- Использует `window.BunkerAuth` для получения списка пользователей и управления ролями.
- Исходник: [js/profile.js](js/profile.js#L1-L200)
