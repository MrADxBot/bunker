# Модуль `js/auth.js`

Описание:

Клиентский модуль аутентификации и управления пользователями. Работает с API `api/users.php`, хранит текущую сессию в `localStorage`.

Основные возможности:
- Регистрация и вход пользователей
- Управление сессией (localStorage)
- Просмотр и управление ролями (только для `admin`)
- Всплывающие уведомления и UI-обработчики для форм

Публичный API:
- `init(onAuthSuccess, options = {})` — инициализация модуля
- `logout()` — выйти из аккаунта
- `isAdmin()` — true, если текущий пользователь админ
- `isAuthenticated()` — есть ли залогиненный пользователь
- `requireAuth(onAuthSuccess)` — откроет оверлей логина, если не залогинен
- `openAuthOverlay(view)` — открыть оверлей (login/register)
- `listUsers()` — вернуть список пользователей
- `updateUserRole(username, newRole)` — изменить роль (только admin)
- `deleteUser(username)` — удалить пользователя (только admin)
- `getCurrentUser()` — вернуть объект текущего пользователя
- `roleLabels` — объект локализованных названий ролей

Замечания и ограничения:
- Модуль использует синхронный `XMLHttpRequest` в функции `request()` — это блокирует поток и может вызывать подвисания в UI.
- Хэш пароля делается на клиенте через `btoa` (легкая защита). Сервер ожидает тот же формат.
