# Модуль `js/game.js`

Описание:

Главная логика игры: подготовка списка игроков, генерация карточек, фазы игры (катастрофа → раскрытие карт → голосование → результаты), рендер UI и синхронизация с онлайн-комнатой через `BunkerRooms`.

Ключевые возможности:
- Управление состоянием игры (`state`) и переходы фаз
- Генерация карточек игроков и описаний
- Отрисовка экранов: setup, catastrophe, game, voting, results
- Поддержка оффлайн-режима и синхронизации с `BunkerRooms` для онлайн-игры

Публичный API:
- `init()` — инициализация и привязка UI-обработчиков
- `resetToSetup()` — сброс состояния и подготовка новой игры

Замечания и интеграции:
- Модуль использует `window.BunkerRooms` для сетевой синхронизации и `window.BunkerAuth` для данных о пользователе.
- Экспортируется как глобальный `window.BunkerGame`.
- Исходник: [js/game.js](js/game.js#L1-L1200)
