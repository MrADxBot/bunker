Правила игры «Бункер»

Сюжет и цель

На Земле глобальная катастрофа. В бункер попадёт только часть группы. Ваша задача — убедить других, что именно ваш персонаж полезен для выживания.

Структура раунда

  • Каждый раунд игроки по очереди раскрывают по одному атрибуту
  • После раскрытия всех атрибутов проводится голосование
  • Игрок с наибольшим числом голосов выбывает
  • Игра продолжается, пока не останется нужное число выживших
